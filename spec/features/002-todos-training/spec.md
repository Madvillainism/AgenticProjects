# Spec - To-Dos Training Queue

## Descripción

Lista de tareas específica para la sesión de práctica actual (ej: "Practicar 10 ewgf seguidos", "Hacer breaking throws contra King"). Cada tarea se asocia a un número específico de repeticiones o un estado de completado.

## Criterios de Aceptación

- El usuario puede añadir, eliminar y marcar tareas como hechas.
- Una tarea completada otorga "puntos de entrenamiento" simulados en el HUD principal de MokuApp.
