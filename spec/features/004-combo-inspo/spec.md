# Spec - Combo Inspo & Pro Directory

## Descripción

Módulo de recopilación de meta-información. No consume APIs externas. Ofrece un glosario estático de jugadores profesionales agrupados por su personaje insignia y automatiza consultas URL codificadas para el usuario.

## Criterios de Aceptación

- Al seleccionar un personaje, muestra las tarjetas de los jugadores de referencia más influyentes.
- Al hacer clic en un pro-player, genera un enlace automático que se abre en el navegador web apuntando a la búsqueda directa en YouTube.
- Permite almacenar en la IndexedDB local un cuaderno de notas con URLs de interés pegadas por el usuario.
