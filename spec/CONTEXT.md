# Kakeibo App - Global Context Ledger

## Estado Actual del Proyecto

- **Fase:** 0 — Fundación Visual (construcción incremental, paso a paso).
- **Entorno:** Local únicamente. Static site. Sin SSR, sin backend, sin frameworks CSS.
- **Enfoque:** Construir la UI con Astro + CSS vainilla. Feature por feature desde cero.

## Restricciones Activas

1. **Zero config.** Astro sin configuración, sin adaptadores, sin integraciones.
2. **Zero frameworks CSS.** Solo CSS vainilla con custom properties (`:root`).
3. **Zero JS runtime.** Static site. Sin servidor.
4. **Incremental.** Un feature a la vez. Cada paso se especifica antes de codificar.
