1. PROJECT OVERVIEW
================================================================================

This tutorial explains how to build a real-time hand gesture recognition system
using Python, MediaPipe, and OpenCV. The system detects hand gestures from a
webcam feed and overlays meme images when gestures are recognized.

Technology Stack:
- Python 3.11+
- MediaPipe Hands (hand landmark detection)
- OpenCV (video capture and display)
- NumPy (mathematical calculations)

3. HAND LANDMARK DETECTION
================================================================================

3.1 MediaPipe Hands Overview
-----------------------------
MediaPipe Hands detects 21 landmarks on each hand in real-time.

Key Landmarks:
- 0: WRIST (reference point)
- 4: THUMB_TIP (thumb tip)
- 8: INDEX_TIP (index finger tip)
- 12: MIDDLE_TIP (middle finger tip)
- 16: RING_TIP (ring finger tip)
- 20: PINKY_TIP (pinky tip)

3.2 Configuration Options
---------------------------
options = vision.HandLandmarkerOptions(
    base_options=base_options,
    running_mode=vision.RunningMode.VIDEO,
    num_hands=2,
    min_hand_detection_confidence=0.7,
    min_hand_presence_confidence=0.7,
    min_tracking_confidence=0.7
)

- num_hands: Maximum hands to detect (1-2)
- min_hand_detection_confidence: Palm detection threshold
- min_hand_presence_confidence: Hand presence threshold
- min_tracking_confidence: Frame-to-frame tracking threshold

4. GESTURE RECOGNITION MATH
================================================================================

4.1 Euclidean Distance Calculation
------------------------------------
The distance between two landmarks is calculated using:

distance = sqrt((x2-x1)^2 + (y2-y1)^2 + (z2-z1)^2)

def _calculate_distance(self, point1, point2):
    return np.sqrt(
        (point1.x - point2.x) ** 2 + 
        (point1.y - point2.y) ** 2 + 
        (point1.z - point2.z) ** 2
    )

4.2 Finger Extension Detection
--------------------------------
A finger is considered extended if its tip is above its PIP joint:

def _is_finger_extended(self, hand_landmarks, finger_tip, finger_pip):
    return hand_landmarks[finger_tip].y < hand_landmarks[finger_pip].y

Note: Y-axis increases downward, so "above" means smaller Y value.

4.3 Thumb Extension Detection
-------------------------------
Thumb is extended upward:
def _is_thumb_extended_up(self, hand_landmarks):
    return hand_landmarks[THUMB_TIP].y < hand_landmarks[THUMB_IP].y

Thumb is extended downward:
def _is_thumb_extended_down(self, hand_landmarks):
    return hand_landmarks[THUMB_TIP].y > hand_landmarks[THUMB_IP].y

5. IMPLEMENTING GESTURES
================================================================================

5.1 Thumbs Up
--------------
Conditions:
1. Thumb tip Y < Thumb IP Y (extended upward)
2. All other fingers curled (tips below PIPs)
3. Wrist-to-thumb distance > 0.15

def _is_thumbs_up(self, hand_landmarks):
    thumb_extended_up = self._is_thumb_extended_up(hand_landmarks)
    other_fingers_curled = self._are_other_fingers_curled(hand_landmarks)
    
    wrist_thumb_dist = self._calculate_distance(
        hand_landmarks[WRIST],
        hand_landmarks[THUMB_TIP]
    )
    
    return thumb_extended_up and other_fingers_curled and wrist_thumb_dist > 0.15

5.2 Thumbs Down
-----------------
Conditions:
1. Thumb tip Y > Thumb IP Y (extended downward)
2. All other fingers curled
3. Wrist-to-thumb distance > 0.15

def _is_thumbs_down(self, hand_landmarks):
    thumb_extended_down = self._is_thumb_extended_down(hand_landmarks)
    other_fingers_curled = self._are_other_fingers_curled(hand_landmarks)
    
    wrist_thumb_dist = self._calculate_distance(
        hand_landmarks[WRIST],
        hand_landmarks[THUMB_TIP]
    )
    
    return thumb_extended_down and other_fingers_curled and wrist_thumb_dist > 0.15

5.3 Victory/Peace Sign
-------------------------
Conditions:
1. Index finger extended (tip Y < PIP Y)
2. Middle finger extended (tip Y < PIP Y)
3. Ring finger curled (tip Y > PIP Y)
4. Pinky curled (tip Y > PIP Y)

def _is_victory(self, hand_landmarks):
    index_extended = self._is_finger_extended(hand_landmarks, INDEX_TIP, INDEX_PIP)
    middle_extended = self._is_finger_extended(hand_landmarks, MIDDLE_TIP, MIDDLE_PIP)
    ring_curled = hand_landmarks[RING_TIP].y > hand_landmarks[RING_PIP].y
    pinky_curled = hand_landmarks[PINKY_TIP].y > hand_landmarks[PINKY_PIP].y
    
    return index_extended and middle_extended and ring_curled and pinky_curled

5.4 Open Palm
---------------
Conditions:
1. Index finger extended
2. Middle finger extended
3. Ring finger extended
4. Pinky extended

def _is_open_palm(self, hand_landmarks):
    index_extended = self._is_finger_extended(hand_landmarks, INDEX_TIP, INDEX_PIP)
    middle_extended = self._is_finger_extended(hand_landmarks, MIDDLE_TIP, MIDDLE_PIP)
    ring_extended = self._is_finger_extended(hand_landmarks, RING_TIP, RING_PIP)
    pinky_extended = self._is_finger_extended(hand_landmarks, PINKY_TIP, PINKY_PIP)
    
    return index_extended and middle_extended and ring_extended and pinky_extended

        if os.path.exists(path):
            img = cv2.imread(path, cv2.IMREAD_UNCHANGED)
            if img is not None:
                img = cv2.resize(img, (150, 150))
                images[gesture_name] = img
    
    return images

6.2 Alpha Blending
--------------------
def overlay_image(frame, overlay, position, alpha=0.8):
    x, y = position
    h, w = overlay.shape[:2]
    
    if overlay.shape[2] == 4:  # Has alpha channel
        # Split into RGB and alpha
        overlay_rgb = overlay[:, :, :3]
        overlay_alpha = overlay[:, :, 3] / 255.0
        
        # Expand alpha to 3 dimensions
        overlay_alpha_3d = np.stack([overlay_alpha] * 3, axis=-1)
        
        # Get region of interest
        roi = frame[y:y+h, x:x+w]
        
        # Blend images
        blended = (overlay_alpha_3d * overlay_rgb + 
                   (1 - overlay_alpha_3d) * roi).astype(np.uint8)
        
        frame[y:y+h, x:x+w] = blended
    
    return frame

7. TESTING & DEBUGGING
================================================================================

7.1 Common Issues
-------------------
Issue: No hand detected
Solution: 
- Ensure hand is fully visible in frame
- Check lighting conditions
- Lower min_hand_detection_confidence

Issue: Gestures not recognized
Solution:
- Adjust distance thresholds
- Ensure hand is in correct position
- Check gesture_engine.py logic

Issue: Jittery landmarks
Solution:
- Increase min_tracking_confidence
- Apply smoothing filter
- Use lower model complexity

7.2 Threshold Tuning
-----------------------
Start with default values:
- min_hand_detection_confidence = 0.7
- min_hand_presence_confidence = 0.7
- min_tracking_confidence = 0.7

Adjust in 0.1 increments:
- Increase for fewer false positives
- Decrease for more detections

7.3 Performance Optimization
-------------------------------
- Use model_complexity=0 for fastest inference
- Limit overlay image size to 150x150
- Cache loaded images
- Process every Nth frame for batch analysis

8. MOUSE CONTROL (PHASE 3)
================================================================================

8.1 L-Shape Gesture (Mouse Mode Toggle)
-----------------------------------------
The L-shape gesture is used to toggle mouse mode on/off.

L-Shape Conditions:
1. Thumb extended outward (distance from wrist > 0.15)
2. Index finger extended upward (tip Y < PIP Y)
3. Middle, Ring, Pinky curled (tips > PIPs)
4. Angle between thumb and index: 60-120 degrees

8.2 Cursor Movement
---------------------
The cursor is controlled by the index finger position.

Index finger tracking:
- Get normalized position: (landmarks[8].x, landmarks[8].y)
- Apply smoothing: exponential moving average
- Map to screen coordinates

8.3 Unified Pinch Handler
---------------------------
Single method handles click, double click, and drawing.

Pinch Logic:
- Quick pinch (<0.35s) = Single click
- Two quick pinches (<0.4s apart) = Double click
- Pinch held (>0.35s) = Start drawing (mouseDown)
- Release pinch = Stop drawing (mouseUp)

def handle_pinch(self, hand_landmarks):
    if is_pinching:
        if not self.pinch_active:
            self.pinch_active = True
            self.pinch_start_time = current_time
        elif not self.is_drawing:
            held_duration = current_time - self.pinch_start_time
            if held_duration > self.draw_confirm_time:
                pyautogui.mouseDown()
                self.is_drawing = True
    else:
        if self.pinch_active:
            held_duration = current_time - self.pinch_start_time
            self.pinch_active = False
            
            if self.is_drawing:
                pyautogui.mouseUp()
                self.is_drawing = False
            elif held_duration < self.draw_confirm_time:
                if current_time - self.last_click_time < self.double_click_window:
                    pyautogui.doubleClick()
                else:
                    pyautogui.click()
                    self.last_click_time = current_time

8.4 Drawing Mode
-----------------
Drawing mode is activated when pinch is held for 0.35 seconds.

Drawing Flow:
1. Pinch fingers together
2. Hold for 0.35 seconds → mouseDown(), drawing starts
3. Move hand to draw
4. Release pinch → mouseUp(), drawing stops
5. Can pinch again to draw another line

Visual indicators:
- "DRAWING" (blue) when drawing
- Blue circle around index finger tip

8.5 Double Click
------------------
Double click is detected when two quick pinches happen in succession.

Double click conditions:
- Two pinches within 0.4 seconds
- Each pinch held for less than 0.35 seconds

Visual indicator:
- "DOUBLE CLICK!" (magenta)

8.6 Scroll Detection
---------------------
Full fingers up = scroll up, full fingers down = scroll down.

All Fingers Up:
- Index, Middle, Ring, Pinky, Thumb all extended upward
- Action: Scroll up

All Fingers Down:
- Index, Middle, Ring, Pinky, Thumb all extended downward
- Action: Scroll down

Visual indicator:
- "SCROLL UP" / "SCROLL DOWN" (yellow)

8.7 Calibration
----------------
Auto-calibration happens during the first 30 frames after enabling mouse mode.

- Tracks min/max X and Y positions
- Maps hand movement range to full screen
- Expands bounds gradually

8.8 Visual Indicators
-----------------------
Status bar at bottom of screen:
- "MOUSE ON" (green) when active
- "DRAWING" (blue) when drawing
- "MOUSE OFF" (orange) when inactive

Action indicators:
- "CLICK!" (red) on single click
- "DOUBLE CLICK!" (magenta) on double click
- "SCROLL UP/DOWN" (yellow) when scrolling
- Blue circle around index finger when drawing
